## 📌 Overview

A collection of GSAP mini-projects built while learning animation for the web. Each folder is a standalone project exploring a different aspect of GSAP — from basic transitions to scroll-triggered animations and timeline sequences.

The idea was simple: learn by building, not just reading docs.

---

## 📁 Projects

| # | Project | Description | Stack |
|---|---------|-------------|-------|
| 01 | [Animated Website](./animated-app/) | Animated landing page with scroll triggers, timelines, and responsive motion design | React + GSAP |
| 02 | [Animations-Practice](./project-02/) | Practice all GSAP animations | React + GSAP |
| 03 | Coming soon | — | — |

## 🛠️ Tech Used

- **GSAP** — GreenSock Animation Platform
- **React.js** — UI framework
- **Tailwind / CSS** — Styling and layout

---

## 🏗️ Running Any Project Locally

Each project is independent. Navigate into the folder and run:

```bash
cd project-name
npm install
npm run dev
```

---

## 🧠 Concepts Explored

- `gsap.to()`, `gsap.from()`, `gsap.fromTo()`
- Timelines — sequencing and controlling animations
- ScrollTrigger — scroll-based animation
- Responsive motion design
- Integrating GSAP with React components
